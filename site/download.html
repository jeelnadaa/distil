Download for Windows

Install

  1. Unzip the download anywhere.
  2. Right-click Install.ps1 and choose Run with PowerShell. Distil installs for your user only, with no admin rights.
  3. Open Distil from the Start menu and add a provider key under Settings › Providers.
  4. Open the How to use Distil chat for a tour.

The app isn't code-signed yet, so Windows may warn you before running the script. Your library lives in ~/Distil, and new versions install from inside the app, under Settings › About.

Run from source

On Windows, macOS or Linux, with Node.js 24 or newer.

git clone https://github.com/jeelnadaa/distil.git
cd distil
npm install
npm run fonts
npm run build
npm start        # http://127.0.0.1:4321
